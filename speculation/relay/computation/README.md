# Relay computation research

This directory is the package-first Relay computation line.

It asks how much apparent language machinery can be reduced to ordinary relative
Development meaning:

1. `development_calculus/`
   - finite canonical Package meaning;
   - `choice`, `or_else`, `and_then`, `each` and `together`;
   - Theory-only dependence remains non-causal;
   - exact captured authority creates actual Worlds causality.
2. `recurrence_calculus/`
   - finite cyclic Package topology;
   - least-positive-fixed-point recurrence without a recursive-call instruction.
3. `formed_computation/`
   - first-class computation as semantic root plus ordinary exact captures;
   - `perform` is Context composition and leaves no finite evaluator residue.
4. `recursive_judgement/`
   - stable recursive eligibility over restrictive positive knowledge.
5. `geometry_viability/`
   - finite authority-boundary Development cases for recursive viability;
   - no parallel authority/effect language.
6. `concurrency_discovery/`
   - the same composition vocabulary used as a concurrency language;
   - a tiny synchronous channel closes as ordinary sibling Geometry;
   - fully known concurrency leaves no scheduler runtime in semantic residue.

Each later laboratory imports the earlier modules it needs. It should extend the
pressure line rather than copy its calculus or Theory implementation.
