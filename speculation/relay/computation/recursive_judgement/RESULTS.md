# Results

## Outcome

The package-pure recurrence representation survives replacement of the toy equality Theory with a
restrictive occurrence-relative knowledge doctrine. Stable recursive preference can be decided without
using the current finite search frontier.

The laboratory passes 27 pressures. The direct pressure suite contains 4,941 assertions, including 4,784
generated regular-doctrine law assertions and 70 generated recursive stability assertions.

## Main findings

### Values are Points plus knowledge

Public value interfaces are symbolic Worlds Points. Exact instantiation produces exact-distinct Points.
Theory relates their extensional values without identifying the Points. Knowledge-only composition creates
no Strand and no Face.

### Construction correspondence is required

Native Construction quotient classes are imposed before hiding. A quotient class which is later
annihilated can still leave a surviving public correlation. Staged restrictive knowledge transport agrees
with one-shot transport.

### Recursive viability is a semantic least fixed point

Judgement computes whether each recursive alternative has any finite complete boundary behaviour. A pure
nonproductive cycle has empty viability. A productive cycle remains viable even when a bounded search has
not yet discovered a witness.

### Stable eligibility is not a frontier

When recursion dominates the base, every bounded search may expose a temporary preferred frontier while
no finite candidate is stable. Every discovered candidate is correctly blocked.

When the grounded base dominates recursion, the base is stable from the first discovery depth onward.

When a preferred recursive branch is positively refuted by current knowledge, the fallback becomes stable.
When that branch is merely Unknown, it remains viable and continues to block the fallback.

A recursive knowledge transition can change the situation for a child occurrence. The lab includes a case
where the preferred recursive step is valid on `true`, transforms the child input to `false`, and therefore
makes the preferred child alternative impossible; the one-step recursive descendant is then stably
eligible.

### Deferred is separate

Depth-zero search over a semantically productive root returns Deferred, not Unknown or Retry. A state which
is genuinely inconsistent with every finite descendant returns Retry even with no discovered candidate.

### Separate compilation survives

Stable Judgement is invariant under canonical Package serialise/reload. Separately compiled recursive roots
linked only by semantic root retain the same eligibility result.

### The restrictive algebra is law-tested

The lab pressures meet associativity, commutativity, idempotence, top/bottom, entailment order,
existential/reindex adjunction, Frobenius reciprocity, hiding/substitution stability, positive fixed-point
reduction, certified observation, and Construction transport composition.

## Deliberate remaining boundary

Stable priority proof is presently exact for the finite value/knowledge boundary used by the lab. Recursive
blocker viability may also depend on exact authority Geometry. The existing recurrence calculus represents
that Geometry correctly, but this Judgement does not yet have a finite exact boundary summary for it.
Authority-bearing recursive roots therefore return Deferred rather than receiving a Theory-based guess.

The natural next research question is whether the exact external authority topology needed for recursive
viability has a tiny finite quotient -- likely boundary identity/incidence plus causal reachability -- which
Judgement can compose alongside the knowledge viability relation without creating a new semantic IR.
