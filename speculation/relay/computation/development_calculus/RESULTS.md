# Transactional Development Calculus — results

The finite package-first model survives 30 pressures with 300 direct assertions.

## Main result

The mechanics used by the radical transactional laboratory are not required for its finite semantic
laws.

For the tested fragment, a transactional computation can be represented extensionally as a
canonical ordered family of relative Developments. `bind` can be implemented as positive Theory
relational composition plus optional exact authority cuts. No continuation callback or packaged
transaction program is required.

This restores the central old-Relay property: portable meaning is semantic meaning. Separate
compilation produces canonical symbolic Development alternatives which can be serialised,
reloaded, linked and freshly instantiated without source or an evaluator being present.

## Particularly strong observations

### Knowledge bind is literally noncausal

Two authority-bearing Rules bound only through value knowledge remain sibling Faces in the
composite Geometry. Neither reaches the other.

Adding one explicit capture cut to the same pair creates the expected causal path. This is visible
in the packaged composite Geometry itself, not in effect metadata.

### Pure bind normalises away

Binding `always(true)` to the packaged value identity produces the same canonical semantic root and
bytes as `always(true)` itself.

Right identity and associativity also hold for the tested finite relation calculus. Associativity
continues to hold for a three-stage authority pipeline built entirely by explicit captures.

### Separate compilation is first-class in every important pressure

Directly composed Packages and independently serialised/reloaded Packages produce identical roots
and bytes for bind, `each`, `or_else` and ambiguous `together`.

The linker mints disposable exact occurrences internally, but native Construction correspondence
lets it erase result allocation order. One hundred fresh capture-link runs and twenty-five fresh
Close-link runs produced identical semantic roots.

### Dependent history need not accumulate

Twenty successive binds through a two-branch boolean relation remain a two-alternative canonical
family. Package size remains constant rather than retaining twenty layers of continuation history.

This does not claim that every programme avoids combinatorial growth. Genuine independent
alternative products still have genuine Cartesian multiplicity. The result is narrower and more
important: hidden sequential formation history is not automatically Package structure.

### Finite value-dependent Geometry can be extensional

A bounded fan-out family for counts zero through three is packaged as four guarded Development
alternatives with a common external authority interface. Specialising the input count leaves the
single corresponding Geometry. There is no fan-out or loop instruction in transport.

This is evidence that some dynamic shape previously implemented by evaluator callbacks can instead
be ordinary relational alternatives.

## Package purity

Canonical Package transport contains no `TransactionContext`, `OutputRef`, live `OrderedFamily`,
coroutine/search object, `perform`, `Live`, bind instruction, call instruction, continuation or
trace.

Each complete family member contains exactly symbolic Geometry, positive Theory, and marked public
interfaces into those two semantic components.

Debug labels and Theory variable spelling are alpha-normalised away. Fresh instantiation creates
fresh exact Strand identity.

### Geometry normal form is scale-invariant

The recurrence experiment exposed a canonicality defect that the original three-stage associativity
pressure missed: longer causal chains could retain symbolic carrier numbering from composition
history. The finite laboratory now structurally alpha-normalises Geometry relative to its marked
public authority interface. Left- and right-associated authority chains agree through eight tested
stages.

This is an important strengthening of the Package claim: portable identity depends on the resulting
relative Development, not the scale or parenthesisation at which it was compiled.

## What the laboratory does not prove

The Knowledge used here is deliberately one symbolic equality domain over the thin host. Later
recursive-Judgement and geometry-viability laboratories exercise occurrence-relative finite relations,
native Construction-correspondence transport and existential hiding over that same host; this finite
calculus itself does not claim to model every eventual Relay domain.

The current linker uses exact Worlds as a normalisation oracle and then erases its exact occurrence.
That is semantically clean and deterministically tested, but a direct symbolic linker would be a
better production mechanism.

The finite family normal form deliberately does not contain unbounded recurrence. `fix` remains
absent here; recurrence is now investigated by a sibling cyclic-Package calculus which preserves this
finite layer unchanged as its base case.

The laboratory also does not yet reconstruct the full old Relay closure/multiplicity system,
Presentation layer, or source type system. Those should remain downstream until recurrence and
restrictive Theory are satisfactory.

## Regression context

The original radical transactional-computation laboratory still passes all 26 pressures unchanged.
The standalone old Relay behavioural suite passes all 100 cases in 23 suites against the same
native-correspondence Worlds candidate, including its Package portability/transport pressures.

The new laboratory therefore changes neither oracle: it is an alternative semantic mechanism being
measured against them.
