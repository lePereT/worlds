# Knowledge-domain contract experiment: results

## Result

The experiments support a substantially smaller and more exact contract for Relay Theory, and the lab now executes that contract through one thin host rather than a feature-rich relation object.

The best current description is: a bottomed regular knowledge doctrine over exact Worlds occurrence
contexts, extended with generic Construction-correspondence transport, positive reduced-product
closure across domains, and certified authority-free observation.

The experiments also found two important failure boundaries: a final partial Construction image is
not enough to transport knowledge compositionally, and several current Relay domain projectors are
not exact existential semantics.

## Executable pressures

The current self-contained research run contains 1,151 assertions:

- 17 direct regular-doctrine/host-boundary laws;
- 11 architectural ratchets enforcing one thin host and native correspondence ownership;
- 5 derived Hit/Retry/Unknown laws;
- 100 alpha/isomorphism equivariance cases;
- 401 generated doctrine pressures, including 200 Beck-Chevalley and 200 Frobenius instances plus a
  generated counterexample to final-partial-image transport;
- 5 tests using actual Worlds 0.6.6 native Construction correspondence with annihilated carriers and staged composition;
- 601 positive-closure/fixed-point laws, including a deliberate non-monotone absence counterexample;
- 6 certified-observation laws;
- 5 exact-versus-abstract solver pressures; and
- historical Relay-domain migration evidence remains documented rather than shipped as part of this
  self-contained runner.

## Strong positive results

Meet/top/bottom with the entailment order is sufficient to derive the semantic judgement triad.
Entailment need not be a primitive protocol.

Existential hiding satisfies adjunction, Frobenius and Beck-Chevalley in the finite relational
model. Hiding does not distribute over meet; shared hidden witnesses can leave public correlation.

Positive cross-domain closure is monotone, idempotent and independent of fair evaluation order in
the generated finite systems. An absence-sensitive rule immediately violates monotonicity.

A successful observation can be represented by a value plus positive certificate. The certificate
is stable under consistent strengthening and can be specialised into a later Rule requirement.
Arbitrary witness selection from ambiguous knowledge is unstable and therefore invalid.

The unchanged current Relay Boolean, Integer, Reference, Structure, Sequence, Index, Focus, Memory,
Hardware, Foreign, Discriminator and Storage modules all ran on a tiny host with no generic schemas,
unification, Theory variables, generic query engine or global Rule proof search. This supports the
claim that those mechanisms are not intrinsic to the domain surface.

## New Construction result

The first minimal Theory lab treated Construction transport as a partial source-to-result image:
survivors were renamed and carriers with nil images were existentially hidden.

That is not compositional in general.

A generated counterexample identifies two source identities in the first stage and later annihilates
the shared intermediate class. Staged transport remembers the equality and can constrain other
surviving knowledge. The composed final partial image sees only that both source identities have
nil image and loses the quotient history.

Worlds 0.6.6 exposes the required quotient classes through native immutable Construction
correspondence, including source-only hidden classes. The thin Knowledge host consumes that evidence
directly; neither the finite relation domain nor any other Theory domain receives Construction or
recreates quotient identity. The old executable corelation/union-find oracle has therefore been
removed from the normative lab rather than retained beside the kernel facility.

## Exact versus abstract Theory

A coarse non-relational abstraction can soundly over-approximate exact knowledge while losing a
correlation created through a hidden witness. This is acceptable for an analyser, but not as the
semantic definition of Theory if Relay wants programme meaning independent of solver precision.

The proposed contract therefore separates exact semantic Unknown from computational Deferred.

## Current-domain incompatibilities

The current Integer solver does not close ordinary `ge` facts transitively. Under the ordinary >=
reading, exact semantics would entail the transitive result where the current domain returns
Unknown.

The current Memory domain gives a stronger counterexample. It can establish transitive reachability
through an intermediate write, then projection hides that write and drops the successor edges. A
subsequent query returns Retry for the same public reachability. Exact existential hiding would
retain the reachability consequence. This is a non-monotone closed-world artefact.

Adopting the exact contract therefore requires some domain redesign, not only a smaller Theory host.

## Negative result: Theory is not current Geometry

The earlier minimal-algebra experiment also tried to represent arbitrary non-authoritative
extensional relations directly with existing Worlds carriers. This changes their meaning: Strand is
authority, Face is causal transformation, Membrane is hierarchical locality, and Point alone cannot
express arbitrary n-ary relation. The four current carriers do not provide a faithful direct
encoding of Theory.

The indexed knowledge fibre remains the better boundary unless a genuinely non-authoritative
relational primitive independently earns a place in Worlds.
