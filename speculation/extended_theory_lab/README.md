# Extended Theory hostile laboratory

**Status: non-authoritative Worlds-only speculation.  No Relay code is imported.**

This branch asks whether a broader notion of Theory can recover Relay's difficult
semantic correlations without adding another operational ontology.

## Hypothesis

A current semantic state is:

```text
Geometry G
+
Theory Phi relative to G
```

Theory may refer directly to any existing exact Worlds carrier:

```text
Point | Strand | Membrane | Face
```

and to literals.  Mentioning a carrier is descriptive only: it grants no
permission to consume, copy, create or relocate that carrier.

Theory also admits alpha-only existential variables.  They are logical
correlation witnesses shared among facts, not Worlds carriers and not programme
authority.

An open operation carries one generic relational rule:

```text
requires
retracts
asserts
```

Requirements are checked against the prior current Theory.  Worlds performs the
exact Construction.  Carrier references rebase only through the exact
Construction image.  Consequences are validated on the complete construction
before boundary hiding.  Facts mentioning carriers absent from the live boundary
are then forgotten.

## Deliberate discipline

The experiment does **not** encode support, recursion, scarcity or causal order
again in Theory.  Membrane ancestry, Point incidence, Strands and Faces remain
exact Geometry and are retained while they are still open/future-relevant.

This is important: the hypothesis under test is a broader **Theory**, not a
universal summary of Geometry.

## What would falsify the Theory hypothesis

A compelling counterexample would require some persistent semantic distinction
which cannot be represented by:

1. exact Geometry retained while still future-relevant;
2. carrier-relative relational facts and alpha-only logical correlation;
3. exact rebasing through lawful Worlds Construction;
4. relational premise checking and explicit consequences;
5. validation before hiding;
6. projection to the current boundary without historical accumulation;

without adding another independent operational state machine.

A failed optimiser, lossy summary, or target-specific analysis is not by itself
such a counterexample.
