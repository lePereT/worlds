# Native Construction correspondence pressure

This experiment takes the correspondence discovered independently by restrictive Theory transport and
the between-Worlds groupoid work and moves the smallest possible part into ordinary Worlds
Construction evidence.

It adds no Geometry carrier and changes no `W.join` result. Ordinary construction image remains the
common source-to-surviving-result projection. A Construction may additionally expose an immutable
correspondence whose opaque classes retain exact quotient identity even when a class has no surviving
result carrier.

The verified join centre already computes the required quotient classes. The experiment retains those
native representatives only when correspondence evidence is requested. Public class values are fresh,
locked evidence objects: they are not Worlds carriers and grant no authority.

The public research surface is intentionally small:

- `construction:correspondence()`;
- source/result class lookup and source equivalence;
- source-to-result correspondence testing;
- composition with a later correspondence whose source includes the previous target plus genuinely
  fresh exact parts;
- source-relative `mate` between exact-distinct targets with the same marked source.

Composition rejects a later part which overlaps the original marked source. Supporting historical
reintroduction of the same exact carrier as a second source occurrence would require occurrence-tagged
source marks rather than pretending a carrier-keyed relation can distinguish the two.

## Pressures

`01_native_transport.lua` reproduces the hidden-quotient Theory transport counterexample and compares
native classes with the prior reconstruction oracle.

`02_groupoid_differential.lua` runs the acyclic and causal-SCC construction atlases. Native class
partitions and endpoint mates are compared directly with the prior reconstruction oracle, then checked
for incidence preservation and exact groupoid composition.

`03_composition_laws.lua` pressures fresh-part composition, one-shot/staged agreement, associativity and
identity.

`04_realisation_fast_path.lua` forces the large-boundary local Match path and verifies that native
quotient provenance survives a prepared `Realisation` and its reuse by `Construction.join`.

Run with `speculation/modern/native_construction_correspondence/run.sh`.
