# Native Construction correspondence results

The experiment succeeds across the current pressures.

The native correspondence repairs the restrictive-Theory transport counterexample: an exact quotient
class may be identified in one stage and annihilated in a later causal SCC, yet its identification can
still constrain surviving public knowledge. Final `Construction:image` alone cannot express that
history; the native correspondence can.

The same native object reproduces the old source-relative between-Worlds groupoids. The differential
suite compares native correspondence against the independent reconstruction oracle for both the
acyclic atlas and the causal-SCC atlas, including many-to-one Face normalisation and Strand
annihilation. It performs 31,403 assertions.

Correspondence composes when later construction introduces genuinely fresh exact parts. Identity and
associativity pass, and staged source partitions agree with equivalent one-shot Construction.

A 96-Strand Match forces the local frame-join fast path. Native quotient provenance survives that path,
the retained `Realisation`, `Construction.from_realisation`, and subsequent exact-witness reuse.

The full unchanged Worlds regression passes, including 440,334 assertions in the advance differential
and all historical algebras. The old restrictive-Theory follow-up, both old construction-groupoid labs,
and the 26-pressure transactional computation laboratory pass unchanged. Current Relay passes its
100-case behavioural suite across 23 suites against this Worlds tree.

A complete speculation sweep was attempted. It reaches a pre-existing failing speculation,
`speculation/relay/cuts_internal.lua`; the same file fails identically against the untouched baseline.
The remaining tail was then run separately. No new failure attributable to this patch was found.

The verified centre compact-source ratchet rises from 22,590 to 23,150 characters. The actual
compact kernel grows from 22,303 to 23,132 characters: 829 additional compact characters of
verified-centre logic. The public correspondence/composition machinery remains outside the centre in
`worlds.construction`.

One indicative benchmark run showed broadly similar timings. The exhaustive 30,240-hit benchmark was
about three percent slower in that run. This is not treated as a stable performance result, only as a
reason to retain a performance pressure before making the evidence mandatory in every Question.

## Interpretation

The experiment supports a sharper model of Construction:

- `image(x)` is the simple surviving representative, if any;
- correspondence retains construction-relative quotient identity, including source-only classes;
- the correspondence grants no authority and cannot mint exact carriers;
- Theory can use it for exact existential transport;
- comparing target fibres over one marked source yields the already-discovered between-Worlds
  coherence maps.

The current implementation should still be treated as a candidate. In particular, query Realisations
currently retain correspondence provenance eagerly for successful exact witnesses. A later performance
pass should decide whether that evidence remains eager, becomes compacted further, or is retained only
for Realisations which cross into Construction.
