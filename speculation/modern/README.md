# Modern 0.6.2 speculation

**Status: non-authoritative executable research.**

These experiments were added without changing Worlds' API, implementation or
laws. They test whether structures which initially looked like candidates for
new ontology are already derivable from interactions among the four carriers.

The current working split is:

```text
Point-Strand incidence     non-causal structural/configurational scope
Strand-Face incidence      scarce causal realisation
Membranes                  hierarchical support with causal availability
Theory/domain algebra      extensional truth under hiding
```

The files intentionally include negative cases. In particular, membrane
cross-axis tests preserve the laminar limitation, Geometry cannot decide
separability from factor scope, and the quantum locality test warns against
turning a global extensional state into scarce causal authority merely to expose
its scope.

Two quantum subprogrammes now live here:

- `quantum_atlas/` attacks contextuality, indistinguishable-particle symmetry,
  interference, phase/transport, copyability, compositional quantum semantics
  and locality using structures already identified in the incidence atlas;
- `quantum_classical/` asks whether recognisably classical states, stochastic
  maps, pointer data, redundant records, local sample spaces, additive history
  probabilities and even classical-looking dynamics can arise as fixed,
  quotient, decohered, copyable or asymptotic sectors of a quantum semantics over
  unchanged Worlds processes.

The latter is summarised in
`../../docs/QUANTUM-CLASSICAL-CORRESPONDENCE.md`. It is deliberately framed as
early correspondence work with explicit falsifiers, not as a physical theory.

All modern experiments are dependency-free Lua/TeX Lua. They use no Python,
SymPy, CAS or external numerical package.

No experiment in this directory is a release law or formal proof.
