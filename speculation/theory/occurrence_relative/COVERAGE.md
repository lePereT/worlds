# Coverage map

This laboratory deliberately imports no Relay code.  The table below maps the
Worlds-only hostile pressures onto the older Relay-pressure laboratory and the
hardest maintained Relay pressures which motivated them.

The goal is **semantic coverage**, not line-for-line reproduction of old helper
objects.  In particular, this experiment deliberately declines to reimplement
factor-shadow support/recursive summaries: where exact open Geometry already
contains the relevant structure, the hostile test retains that Geometry and
asks Worlds directly.

## Deliberate non-coverage

This experiment does not claim to replace or test:

- Relay source syntax or static grade diagnostics;
- Package serialisation/fingerprinting as an artefact format;
- Back representation choice or target emission;
- distributed `Unknown`/`Retry` knowledge;
- the complete Relay weak-memory protocol (X32 tests only the future-relevant
  boundary/history principle);
- a universal Theory solver.

Those are not silently treated as solved by the extended-Theory result.
