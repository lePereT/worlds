# Current semantic showcases

`showcases/` collects the strongest current Relay-facing research built on Worlds 0.6.6.
These laboratories are executable speculation, not additional Worlds ontology.

Two lines are maintained here:

- `theory/` constrains occurrence-relative knowledge so Theory cannot become a
  second authority or execution system;
- `transactions/` builds package-first transactional meaning from relative
  Developments, recurrence, stable Judgement and exact authority viability.

The laboratories intentionally keep Geometry authoritative. Exact identity,
scarcity, locality and causality remain Membrane/Point/Strand/Face structure.
Theory may constrain and observe that structure but does not own it. Transaction
search may discover witnesses but does not become programme meaning.

Run all showcases from the repository root with:

```sh
make showcase-check
```

The release Lua 5.1 syntax gate includes these laboratories. Their compact
research source is checked by `showcase-check` rather than the production
100-column/no-semicolon style gate.
