# Restrictive recursive Judgement laboratory

This research layer sits on top of the package-pure finite and recurrence calculi.

Run with:

    sh speculation/showcases/transactions/transactional_recursive_judgement/run_lab.sh

The lab asks two questions together:

- can the toy equality Theory be replaced by the restrictive occurrence-relative positive doctrine; and
- can recursive `or_else` commitment be proved semantically rather than inferred from bounded search?

The answer is yes for the finite knowledge boundary tested here. The lab deliberately returns `Deferred`
for authority-rich recursive eligibility until Judgement has an exact finite boundary-Geometry summary.
