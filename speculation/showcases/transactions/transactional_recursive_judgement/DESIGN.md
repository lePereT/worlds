# Stable recursive Judgement with restrictive occurrence-relative knowledge

## Thesis

This laboratory combines two pressures without changing the package-pure recurrence thesis.

1. Recursive Package meaning remains a finite cyclic presentation of open Development contexts.
2. The recurrence lab's free Theory variables are replaced by exact occurrence-relative positive knowledge.
3. Search is allowed to expose finite descendants in any order or at any finite depth.
4. Commit eligibility is established independently by Judgement from the recursive semantic fixed point.

A public value slot is now a symbolic Worlds Point. Theory constrains the extensional value observed at
that Point. Equating two public values is a Theory relation between two exact-distinct Points; it is not
Point identification and creates no authority or causal edge.

## Restrictive knowledge doctrine

The research knowledge implementation is an exhaustive finite-model oracle. It is intentionally not a
production solver. For each finite occurrence context it provides top, contradiction, finite meet and the
information order. Hit, Retry and Unknown are derived from that order.

Exact substitution/reindexing preserves meet. Hiding is existential projection. Construction transport
uses native Construction quotient classes: source occurrences in the same class are constrained to agree
*before* a class with no survivor is hidden. Observation returns a determinate value only with a positive
certificate entailed by current knowledge.

The laboratory also pressures positive cross-domain fixed-point reduction, Frobenius reciprocity,
existential/reindex adjunction, and stability under exact Construction composition.

No retraction operation exists.

## Recursive viability

For a recursive root X, Judgement first computes the least fixed point of finite boundary viability.
Each root denotes a relation over its public input/output value boundary. A recursive clause contributes
only when all of its holes have finite viable descendants. Explicit alternatives are combined at the
Judgement level; this union is not added to Theory.

Thus a pure ungrounded cycle has empty finite viability. A grounded recursive cycle has non-empty
viability even if a bounded search has not yet found a witness.

For each alternative, Judgement retains its own fixed-point viability relation. This is what ordered
preference consults.

## Stable eligibility

Search returns an ephemeral finite candidate and a derivation tree. The derivation is not Package meaning.
Judgement verifies the candidate recursively.

At each chosen alternative:

- the candidate's positive input requirement must be Hit in its contextual knowledge;
- its complete boundary behaviour must remain consistent with the context;
- every alternative which dominates it must have *no* finite viable completion consistent with that same
  context; and
- every recursively selected child must satisfy the same condition in the child environment induced by
  the parent context, outer knowledge, and the chosen sibling descendants.

A dominating alternative which is merely Unknown remains viable and therefore blocks commitment. Only
positive contradiction/exclusion releases the dominated candidate.

This makes the finite `OrderedFamily.frontier` deliberately irrelevant to recursive commit eligibility.
A branch may sit at every bounded frontier and still never be stable at the least fixed point.

## Deferred

`Deferred` is computational, not semantic Theory.

If the recursive denotation remains viable but the current discovery has no certified stable witness,
Judgement returns Deferred rather than turning bounded search exhaustion into Unknown or Retry.

The current stable-eligibility analyser is exact for the finite occurrence-knowledge boundary exercised by
this laboratory. It does not yet contain a finite exact summary of authority-dependent boundary Geometry.
Therefore authority-bearing recursive roots are explicitly Deferred by this Judgement rather than guessed
from Theory alone. The recurrence calculus continues to represent their semantic meaning normally.

This restriction is intentional: the missing abstraction belongs to Geometry/Judgement, not Theory.

## Package purity

The restrictive recursive Package contains only canonical Development contexts, hole-to-root topology and
ordered-family dominance. Serialisation/reload and separate semantic-root linking preserve Judgement.
No continuation, callback, bytecode, coroutine, evaluator state or recursive instruction is introduced.

## Construction integration

Knowledge transport uses the native Construction correspondence retained by the preceding Worlds lab.
That evidence is necessary because final `Construction:image` loses source identifications whose quotient
class is later annihilated. Identifications are applied before existential hiding, and staged transport is
required to agree with one-shot transport.
