# Transactional Geometry viability laboratory

This research laboratory closes the deliberate authority-recursion gap left by
`speculation/showcases/transactions/transactional_recursive_judgement`.

It asks whether stable recursive `or_else` can be proved when blocker viability depends on exact authority
Geometry as well as restrictive occurrence-relative knowledge, without introducing effect/capability
metadata or a recursive evaluator.

The answer in the pressured fragment is yes. The semantic fixed point is a finite set of canonical
**boundary Development cases**. Each case keeps a complete exact open-authority quotient and its joint
positive boundary Theory together. The current suite includes hostile capture, split/merge, locality,
feedback-annihilation, mutual-recursion and cross-root-priority pressures.

Run with:

    speculation/showcases/transactions/transactional_geometry_viability/run_lab.sh

The laboratory is research-only. Production Worlds and Relay semantics are not changed by these files.
See `DESIGN.md` for the model and `RESULTS.md` for the pressure summary and remaining caveats.
