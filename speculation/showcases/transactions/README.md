# Package-first transactional showcase

This showcase replaces the older computation-boundary and transactional-
computation experiments. It keeps the strongest semantic laws discovered there
but rejects their evaluator-shaped mechanics.

The governing rule is:

> Separately compiled Relay meaning is semantic meaning, not executable code
> which later manufactures semantic meaning.

Portable transactional elements are therefore finite canonical presentations of
relative Development meaning: symbolic Worlds Geometry plus restrictive Theory,
with alternative/dominance structure where required. Fresh exact identity is
created only when that meaning is instantiated.

1. `transactional_development_calculus/`
   - finite transactional meaning;
   - bind as Theory composition plus explicit exact cuts;
   - `or`, `or_else`, Cartesian `each`, whole-sibling `together`;
   - separate compilation and scale-invariant Package normal form;
   - no Comp VM, continuation callbacks or transaction state in Package.

2. `transactional_recurrence_calculus/`
   - recursion as a finite cyclic Package graph of open Development contexts;
   - finite unfoldings equal direct finite compilation;
   - recurrence topology disappears from every completed finite descendant;
   - no recursive call instruction or semantic stack object.

3. `transactional_recursive_judgement/`
   - restrictive occurrence-relative Theory replaces the toy equality layer;
   - recursive eligibility is semantic viability, not the current search frontier;
   - dominance is stable only when all dominating finite descendants are proved
     impossible under the current exact/knowledge boundary.

4. `transactional_geometry_viability/`
   - authority-dependent recursion closes the remaining gap;
   - viability is the least fixed point of canonical boundary Development cases;
   - Geometry and Theory remain correlated rather than being analysed by two
     independent effect summaries;
   - the boundary quotient retains exact authority identity, ordered Point
     incidence, Membrane ancestry and causal reachability, while erasing closed
     internal history.

transaction still collapses to one ordinary Rule Development before generic
Judgement/Live. Search, unfolding history and optimisation state remain outside
the semantic airlock.
