# Candidate package-pure recurrence calculus

## Thesis

The finite transactional calculus remains unchanged as a semantic basis:

`Finite<A> = OrderedFamily<RelativeDevelopment<A>>`.

Unbounded recurrence is not added as a `fix` node to that calculus. Instead a recursive Package is a
finite system of equations whose clauses are **open relative Development contexts**. Every clause is
symbolic Worlds Geometry plus positive Theory with marked outer interfaces and zero or more marked
holes. A hole points to another semantic Package root.

A hole is not a call instruction. Filling it means only:

1. fresh-instantiate the target relative Development;
2. cut the hole's authority boundary to the target boundary by ordinary Worlds Construction;
3. equate the corresponding positive value knowledge;
4. existentially hide the internal boundary;
5. canonicalise the resulting relative Development.

No evaluator object survives that operation.

## Denotation

For recursive roots `X1 ... Xn`, Package defines a finite positive equation system

`Xi = Fi(X1, ... Xn)`

where each `Fi` is built from finite ordered-family alternatives, Cartesian products for multiple
holes, positive Development context filling, and ordinary preference lifting.

The intended denotation is the least fixed point in the ordered-family domain. The laboratory
constructs its finite Kleene approximants:

- `X(0) = empty`;
- `X(k+1) = F(X(k))`.

The approximation depth is not runtime fuel and is not Package meaning. It is a research operation
for observing finite portions of the denotation. Each member of every finite approximant is an
ordinary finite Package alternative containing one relative Development and no recurrence residue.

## Package identity

Local source definition names are not semantic identity. Recursive definitions are partitioned into
SCCs. The research Package canonicalises each SCC anonymously, derives a content fingerprint, and
then derives entry roots from the canonical SCC meaning.

The current research implementation uses brute-force permutation inside SCCs of at most seven
members. This is deliberately a correctness oracle, not a proposed production algorithm.

Structurally indistinguishable recursive entries may therefore share one semantic root. Public
source names can still map to that root as non-semantic presentation/correspondence data.

External dependencies are already-resolved semantic roots. Linking Packages is content-addressed
union with collision checking. No source is required.

## Compilation scale

The central law is:

> If a finite recursive unfolding can be compiled directly as one larger finite region, the direct
> compilation and the unfolded recursive Package must have identical finite Development meaning.

This pressure exposed a defect in the original finite laboratory: symbolic Geometry numbering could
retain Construction parenthesisation after three or more authority stages. The finite lab now applies
a structural alpha-normal form to Geometry with its marked public authority interface. Recursive
unfolding and whole-region compilation agree byte-for-byte through the tested scales.

The research Geometry canonicaliser uses colour refinement plus bounded symmetry enumeration. It is
again a correctness mechanism, not yet a production algorithm.

## Preference and infinite recurrence

Preference is semantic ordered-family structure, so recurrence exposes an important distinction
between finite discovery and limit eligibility.

If a recursive alternative dominates a grounded base, every finite approximant can have a temporary
frontier consisting of its deepest completed recursive descendant. At the limit every such finite
descendant is dominated by a deeper one; there is no stable finite frontier.

Therefore a judge may not commit merely because the current bounded unfolding has a frontier.
Bounded exploration and semantic eligibility are different notions.

Conversely, if the grounded base dominates the recursive alternative, its frontier is stable from
the first approximant onward.

## Nonproductive cycles

A pure equation such as `X = step(X)` with no grounded alternative has empty least finite meaning.
This does not imply that a bounded implementation may report semantic `Retry` merely because it has
not found a witness. Proving that an arbitrary recursive Package has empty denotation is a separate
solver/decision problem. Failure to prove it belongs to computational `Deferred`/resource policy,
not semantic `Unknown` or false refutation.

## Deliberate remaining pressures

This laboratory inherits the finite lab's tiny positive equality Theory. It has not yet integrated
the full restrictive occurrence-relative knowledge doctrine or native Construction-correspondence
transport of domain facts.

It also does not yet pressure higher-order recursive closures, recursive environment capture across
Package roots, or a production judgement algorithm over the infinite family. Those are downstream
questions. The semantic Package representation should remain fixed while they are investigated.
