# Candidate finite calculus

The proposed finite semantic equation is:

`Computation<A> = OrderedFamily<RelativeDevelopment<A>>`.

This is a denotation, not a runtime representation requirement.

A `RelativeDevelopment` is symbolic Worlds Geometry plus positive Theory with marked public
boundary positions. The marks are interface/presentation evidence and carry no authority.

The finite operators are required to close inside this denotation:

- alternatives operate on the outer ordered family;
- positive composition operates on Geometry;
- dependent value composition operates on Theory and existentially hides the intermediate value;
- explicit capture contributes exact Strand equations to the same positive composition;
- Close discovers exact sibling equations for `together`;
- completed alternatives are already one Development.

No evaluator node is semantically required for these operations.

The unresolved extension is recurrence. The desired future theorem is not that `fix` executes a
Package program, but that a finite portable recurrence object denotes the least fixed point of
relative Development meaning while preserving old Relay's content-addressed SCC identity and fresh
exact instantiation.
