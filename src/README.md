# Worlds 0.2 source map

```text
src/
  worlds.lua
  worlds/
    model.lua                 four-object carrier
    topology.lua              derived detached patch/boundary topology
    attachment.lua            public Att(K) retained query surface
    attachment_reference.lua  exhaustive research/test oracle (not public)
    graft.lua                 fresh actualisation of a witnessed attachment
    audit.lua                 resource/provenance/causality checks
    harden.lua                public Model facade
    harden_core.lua           Lua trust-boundary implementation
    internal.lua              package-internal hardened adapter
    certified.lua             immutable certified primitive observation
    separate.lua              portable detached geometry
    frontier.lua              artefact-level Point-row abstraction
    completion.lua            retirement judgement
```

The carrier does not contain Attachment/query/search objects. `topology.lua`,
`attachment.lua` and `graft.lua` are constructions around the carrier.

Non-public reference helpers are kept only when they provide an independent
oracle or a small transparent implementation aid for ongoing research.
