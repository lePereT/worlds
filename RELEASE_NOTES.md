# Worlds 0.1.0

This is the first external-consumer release of Worlds.

The semantic carrier remains deliberately small:

```text
World   locality, custody and actual ancestry
Point   semantic identity
Strand  one occurrence of authority
Face    transformation
```

Detached World components are reusable possibility. `develop` matches their open frontier against local unspent authority and grafts fresh generated Worlds into actuality. Successful development now rejects non-linear late aliasing before any graft.

0.1 also includes the first generic separate-compilation abstraction above the kernel. A portable artefact may contain a variadic Point-row frontier variable; `specialise` substitutes only sort/order/equivalence shape and produces an ordinary closed Separate unit. Actual generative identities are still supplied later through `develop`.

The intended first consumer is Relay. The release is `0.x`: the core laws are serious, but API and format details may still tighten as formal verification and additional consumers apply pressure.
