# Formalisation programme

**Status: non-authoritative formalisation programme.**

Start from `../docs/MODEL.md`, `../docs/LAWS.md` and `../docs/THEOREMS.md`, not the Lua implementation.

A useful first mechanised core should define finite nested open Geometry, exact

history/boundary commuting square rather than introduced as additional semantics.
